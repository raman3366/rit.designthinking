# GE261004 — Design Thinking

Course material for **GE261004 Design Thinking**, an undergraduate engineering course taught at
Rajalakshmi Institute of Technology, Chennai. This repository holds the syllabus, the full set of
lecture presentations and the detailed lecture notes for all five units.

| | |
|---|---|
| **Course code** | GE261004 |
| **Course title** | Design Thinking |
| **L – T – P – C** | 2 – 0 – 0 – 2 |
| **Total periods** | 30 (five units of 6 periods each) |
| **Instructor** | Dr. Anantha Raman L., M.E., Ph.D. — Associate Professor, Department of Mechanical Engineering |
| **Institution** | Rajalakshmi Institute of Technology, Chennai, Tamil Nadu |

**Course objective.** To introduce students to the principles of design thinking and enable them to
identify real-world problems, generate innovative ideas, and develop user-centred solutions through
creativity, collaboration and iterative design processes.

---

## What is in this repository

```
.
├── 01 SYLLABUS/          1 PDF   — the approved course syllabus (2 pages)
├── 02 PRESENTATIONS/    30 PDFs  — six lecture decks per unit (≈486 slides)
└── 03 LECTURE NOTES/     5 PDFs  — one set of detailed notes per unit (≈92 pages)
```

Everything is distributed as PDF, so it opens on any device without special software. The
presentations are 16:9 slide decks; the lecture notes are A4 reading material with worked examples,
Indian and international case studies, and review questions at the end of every unit.

### Naming convention

| Folder | Pattern | Example |
|---|---|---|
| Presentations | `GE261004_Unit_<Unit>_<NN>_<Topic>.pdf` | `GE261004_Unit_II_02_Empathy_Mapping.pdf` |
| Lecture notes | `GE261004 - Unit <Unit> - Lecture Notes.pdf` | `GE261004 - Unit III - Lecture Notes.pdf` |

The two-digit number in a presentation filename is its position in the unit, so sorting a folder by
name gives the teaching order.

## Course outcomes

At the end of the course, students will be able to:

| | Outcome |
|---|---|
| **CO1** | Explain the principles and stages of the design thinking process. |
| **CO2** | Identify user needs and formulate problem statements using empathy-based approaches. |
| **CO3** | Generate and evaluate innovative ideas using structured ideation techniques. |
| **CO4** | Develop basic prototypes and test solutions through iterative design methods. |
| **CO5** | Present sustainable and innovative engineering solutions addressing real-world problems. |

Each unit maps to one course outcome in order: Unit I → CO1, Unit II → CO2, Unit III → CO3,
Unit IV → CO4, Unit V → CO5. The CO–PO/PSO articulation matrix is given on page 2 of the
[syllabus](01%20SYLLABUS/GE261004%20-%20DESIGN%20THINKING%20-%20Syllabus.pdf).

## How to use this material

**Students.** Read the unit's lecture notes first — they carry the full explanation, the worked
examples and the review questions (two-mark and thirteen-mark) you will be examined on. Use the six
presentations as a recap of the same unit in teaching order; they are condensed versions of the
notes, not a substitute for them. Download the PDFs rather than reading them in the GitHub preview,
which renders large files slowly.

**Faculty.** Each unit is six presentations for six periods, so one deck maps to one class hour. The
decks open in any PDF reader in presentation mode; the notes can be issued as unit-wise handouts.

To get a local copy of everything:

```bash
git clone https://github.com/<user>/rit.designthinking.git
```
